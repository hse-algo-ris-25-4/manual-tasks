## Восстановление оптимального распределения

По итогу максимальная прибыль при вкладе 500 рублей равна **15**.
Возможно два варианта оптимального распределения, так как при вложении 100 рублей в проекты A и B прибыль одинаковая.

1. `100\*A + 0\*B + 100\*C + 300\*D + 0\*E = 15`<br>
Проверка: 3 + 0   +   4    +   8    +  0   = 15

2. `0\*A + 100\*B + 100\*C + 300\*D + 0\*E = 15`<br>
Проверка: 0 + 3   +   4    +   8    +  0   = 15

## Проверка ответа

- Сумма вложений равна общему объему (100 + 0 + 100 + 300 + 0 = 500).
- Прибыль по каждому проекту соответствует таблице варианта.
- Суммарная прибыль = 15 максимальна, т.к. был перебор всех возможных вариантов распределения вложений (от 100 до 500).
