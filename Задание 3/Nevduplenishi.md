## Логика
Реализовываем динамическое программирование ручками. Т.е. сначало берём столбцы для двух проектов, считаем для них оптимальное распределение, потом добавляем следующий проект и считаем оптимальное распределение, пользуясь прошлым оптимальным распредлением с прошлого этапа.

## Расчёты

**Варианты для суммы 100:**
- 100A = 3
- 100B = 3  
  
Разницы нет, берём 100A

**Варианты для суммы 200:**
- 200A = 5
- 200B = 4
- 100A + 100B = 6
  
Самый выгодный вариант 100A + 100B = 6

**Варианты для суммы 300:**
- 300A = 7
- 300B = 6
- 200A + 100B = 8
- 100A + 200B = 7

Самый выгоднй вариант 200A + 100B = 8

**Варианты для суммы 400:**
- 400A = 8
- 400B = 7
- 200A + 200B = 9
- 100A + 300B = 9
- 300A + 100A = 10

Самый выгодный вариант 300A + 100A = 10

**Для суммы 500:**
- 500A = 12
- 500B = 11
- 400A + 100B = 11
- 100A + 400B = 10
- 200A + 300B = 11
- 300A + 200B = 11
  
Самый выгодный вариант 500A

|-------|-------|----|------|----------------|

В итоге при сумме 500 максимальная прибль равна 15. А теперь раскладываем решение:  
500ABCD = 200ABC + 300D  
200ABC = 100AB + 100C  
100AB = 100A  
Получаем итоговую формулу для: *100A + 100C + 300D = 3 + 4 + 8 = 15*  

**Ответ:** 15; A = 100, B = 0, C = 100, D = 300, E = 0
